## Recommended Skills

| Skill | Why |
|-------|-----|
| `/daily-plan` | Prioritize deals by stage and close date |
| `/meeting-prep` | Prep for customer calls with account history and context |
| `/quarter-plan` | Set revenue targets and account strategy per quarter |
| `/process-meetings` | Capture customer commitments and next steps |
| `/triage` | Sort incoming leads and requests by priority |
| `/review` | Track daily wins and pipeline movement |

## Typical Week

```
Monday    → /week-plan (deal priorities + target accounts)
Daily     → /daily-plan (call prep + pipeline updates)
Wednesday → /project-health (deal stage review)
Friday    → /week-review (pipeline movement + forecast update)
```
