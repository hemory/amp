## Recommended Skills

| Skill | Why |
|-------|-----|
| `/daily-plan` | Track multiple workstreams and deadlines daily |
| `/meeting-prep` | Prep for steering committees and cross-team syncs |
| `/project-health` | Scan all active programs for blockers and risks |
| `/quarter-plan` | Align program milestones with organizational goals |
| `/triage` | Route incoming requests to the right workstream |
| `/process-meetings` | Capture decisions and action items from every sync |

## Typical Week

```
Monday    → /week-plan (program priorities + risk flags)
Daily     → /daily-plan (dependency tracking + stakeholder comms)
Wednesday → /project-health (mid-week program health scan)
Friday    → /week-review (status roll-up + blockers resolved)
```
