## Recommended Skills

| Skill | Why |
|-------|-----|
| `/daily-plan` | Balance program design with stakeholder requests |
| `/meeting-prep` | Prep for facilitator check-ins and stakeholder reviews |
| `/product-brief` | Design new programs with structured PRD approach |
| `/quarter-plan` | Set program delivery targets and impact goals |
| `/project-health` | Track active programs through ADDIE lifecycle |
| `/process-meetings` | Capture feedback from program evaluations |

## Typical Week

```
Monday    → /week-plan (program deliverables + stakeholder comms)
Daily     → /daily-plan (content creation + facilitation prep)
Wednesday → /project-health (program delivery tracking)
Friday    → /week-review (participant feedback + metrics review)
```

## L&D-Specific Frameworks

Consider adding these to your USER_EXTENSIONS block:

- **Performance Analysis (BEM):** Training only solves Knowledge/Skill gaps
- **Learning Design (Bloom's):** Target Apply or Analyze level for workshops
- **Evaluation (Kirkpatrick):** L1=Reaction, L2=Learning, L3=Behavior, L4=Results
