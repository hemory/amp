## Recommended Skills

| Skill | Why |
|-------|-----|
| `/daily-plan` | Start each day with sprint awareness + team blockers |
| `/meeting-prep` | Prep for 1:1s with report context and action items |
| `/week-plan` | Align sprint goals with quarterly engineering objectives |
| `/career-coach` | Track and grow your team's career development |
| `/project-health` | Monitor active engineering projects for risks |
| `/process-meetings` | Capture standup and retro decisions automatically |

## Typical Week

```
Monday    → /week-plan (sprint goals + team priorities)
Daily     → /daily-plan (blockers, PR reviews, 1:1 prep)
Wednesday → /project-health (mid-sprint check)
Friday    → /week-review (velocity, team morale, learnings)
```
