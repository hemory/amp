## Recommended Skills

| Skill | Why |
|-------|-----|
| `/daily-plan` | Balance stakeholder requests with deep product work |
| `/meeting-prep` | Prep for customer calls, eng syncs, leadership reviews |
| `/product-brief` | Generate PRDs through guided questions |
| `/quarter-plan` | Set product goals aligned with company OKRs |
| `/project-health` | Track feature delivery across multiple workstreams |
| `/process-meetings` | Capture decisions from design reviews and standups |

## Typical Week

```
Monday    → /week-plan (top product priorities for the week)
Daily     → /daily-plan (stakeholder meetings + focus time)
Wednesday → /project-health (feature delivery tracking)
Friday    → /week-review (what shipped, what slipped, learnings)
```
