# User - STYLE

This optional file teaches Amp how to draft in the user's voice.

Prompts to fill in:

- How formal or casual should your writing sound?
- What phrases or structures do you use often?
- What phrases should Amp avoid?
- How direct should asks be?
- How do you usually structure Slack messages, emails, docs, and updates?
- Add 1-3 short examples of writing you like, with notes about why they work.

When Amp drafts on your behalf, it should use this file before applying generic writing advice.
