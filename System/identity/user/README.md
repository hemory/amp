# User Identity Templates

Create `SOUL.md` and `STYLE.md` in this folder only when the user wants persistent identity or voice guidance.

Suggested files:

- `SOUL.md` - user-declared identity, values, working context, and constraints
- `STYLE.md` - how to write in the user's voice for drafts, messages, and external-facing documents

Use placeholders and examples until the user provides real preferences. Do not infer sensitive identity attributes.
